## 🚀 Featured Projects

### ⚙️ [Vehicle Insurance MLOps Pipeline](https://github.com/Prakhar141205/Vehicle-Insurance-ML-Production-MLOps-Pipeline)
A production-style ML pipeline for insurance claim prediction — built to demonstrate ML *engineering*, not just model training.

**Tech:** Python · scikit-learn · FastAPI · Docker · MongoDB · AWS S3 · GitHub Actions

**Highlights**
- Full pipeline: data ingestion → validation → transformation → training → evaluation → model registry
- MongoDB Atlas for data storage, AWS S3 for model versioning
- FastAPI service for real-time predictions, containerized with Docker
- CI/CD automation via GitHub Actions

[View Repository →](https://github.com/Prakhar141205/Vehicle-Insurance-ML-Production-MLOps-Pipeline)

---

### 🧠 [Transformer From Scratch](https://github.com/Prakhar141205/Transformer-Implementation-)
A generalized Transformer architecture implemented from scratch in PyTorch, inspired by *Attention Is All You Need* — built to understand the mechanics, not just call an API.

**Tech:** Python · PyTorch

**Highlights**
- Multi-head and scaled dot-product attention implemented manually
- Full encoder–decoder stack with position-wise feed-forward layers
- Layer normalization, residual connections, and attention masking

[View Repository →](https://github.com/Prakhar141205/Transformer-Implementation-)

## 🧭 Engineering Mindset

I'd rather understand a system than just use it. That means implementing
architectures like Transformers from first principles instead of only
importing them, tracing algorithms like Dijkstra's by hand before running
them at scale, and building ML pipelines end-to-end — data, training,
evaluation, APIs, and deployment — instead of stopping at a notebook.
Reproducibility and clean infrastructure matter as much as model accuracy.
